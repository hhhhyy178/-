# BonjourLab Windows 免安装包

[点击下载 BonjourLab-Windows.zip](https://github.com/hhhhyy178/-/raw/refs/heads/main/downloads/BonjourLab-Windows.zip)

适用于 Windows 10/11 x64，约 65 MB，内置运行时，无需安装 Node.js。

1. 下载 ZIP 后，右键选择「全部解压」。
2. 打开解压后的 BonjourLab 文件夹，双击「启动 BonjourLab.cmd」。
3. 浏览器自动打开后，点击「开始第一节课」。

保持启动窗口开启。学习记录保存在 data 文件夹，下次仍双击同一个启动文件即可。

如果直链未打开，请回到本文件夹，点击 BonjourLab-Windows.zip，再点文件页面右上角的下载按钮。私有仓库需要先登录有权限的 GitHub 账号。

SHA-256 校验值见同目录 SHA256SUMS.txt。程序在 Linux 中验证了独立包学习流程，Windows .cmd 双击启动尚未在真实 Windows 电脑实测。
